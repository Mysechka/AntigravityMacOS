# Antigravity в России без VPN и смены региона аккаунта Google.

Программа для windows, которая позволяет аккаунту Google любой страны (в том числе России) использовать Antigravity.

Видеоинструкция: https://youtu.be/aybWT_7wtqA

Процедура разблокировки проводится один раз для компьютера. После этого можно авторизовываться с любыми аккаунтами Google из любых стран. При обновлении Antigravity - анлокер его пропатчит автоматически. Все изменения можно откатить.


# Где скачать?

Нажимаете на [Releases](https://github.com/confeden/Antigravity/releases) и скачиваете последнюю версию.

Для разблокировки нужно ввести бесплатный лицензионный код, взять можно из группы (в закреплённых сообщениях) [t.me/nova_txt](https://t.me/nova_txt/69864)

# Как разблокировать Antigravity?
1) скачиваете Antigravity/Antigravity IDE/Antigravity CLI с официального сайта [https://antigravity.google/download](https://antigravity.google/download) и устанавливаете
2) применяете анлокер
3) запускаете Antigravity и входите в аккаунт Google

# Работает ли анлокер для 2+ версии?
Да, он работает для всех агентских программ для кодинга от Google:
- Antigravity 2.0
- Antigravity IDE
- Antigravity CLI
- Gemini CLI

# Что именно анлокер меняет в системе?

Ровно три вещи, всё обратимо (пункт меню «Полный откат»), плюс переменная среды `HTTPS_PROXY`, указывающая на локальный прокси `127.0.0.1:53129` (см. ниже). Прокси не расшифровывает TLS и не ставит сертификатов: для двух гейт-хостов CloudCode он выбирает маршрут по замеренной скорости (напрямую по подменённому адресу, через ваш прокси, через запасные пути), всё остальное пропускает как есть. Если у вас уже задан свой `HTTPS_PROXY` или `http.proxy` в настройках Antigravity, анлокер его не трогает и свой не ставит.

1. **Бинарник Language Server / CLI** (`language_server.exe`, `agy.exe`) — переименовывается одно поле в protobuf-дескрипторе (`ineligible` → `inexigible`). Длина строки та же, размер и структура файла не меняются.
2. **NRPT-правила DNS** — только 2 конкретных хоста, к которым обращается сам Antigravity, направляются на DNS xbox-dns.ru:
   `daily-cloudcode-pa.googleapis.com` и `generativelanguage.googleapis.com`.
   Остальной DNS-трафик (в том числе `accounts.google.com` и прочие `*.googleapis.com`) идёт через ваш обычный резолвер.
3. **Приоритет IPv4 над IPv6** — применяется только если на машине нет глобального IPv6-адреса, и снимается при откате.

Файлы `app.asar` начиная с Antigravity 2.4 не распаковываются и не изменяются вообще.

### Чего нет в исходниках:

Быстрые маршруты используют адреса чужих прокси-серверов и ключ доступа к релею, которые **не публикуются** в этом репозитории (лежат в файлах, исключённых из git). Причина не в секретности метода — он обычный `CONNECT`, и весь код работы с ним открыт, — а в том, что публично названный бесплатный сервис быстро перестаёт быть бесплатным.

Поэтому бинарь, **собранный из публичного исходника**, компилируется и полностью работает, но **без быстрых маршрутов** — только по DNS-способу, а он сам по себе полностью разблокирует Antigravity. Свой собственный прокси при этом можно указать в любой сборке: пункт меню 1 спрашивает про него отдельно.

# На virustotal могут быть срабатывания. Почему?

Антивирусы (в особенности бесплатные) любят тревожиться, когда не могут найти известные сигнатуры файла, когда у него отсутствует платная подпись и просто тогда, когда их содержимое сложнее, чем обычно. Исходный код открыт для анализа, но если вы не доверяете - используйте его на виртуальной машине.

# Antigravity Unlocker — Linux (бета порта)

Разблокировка Antigravity 2.0 / IDE / CLI на Linux. Делает две вещи:

1. **Патч клиентских бинарников и JS** — снимает проверку eligibility.
2. **Прокси-маршрут (обход ошибки 400 «User location is not supported»)** —
   поднимает локальный прокси и уводит запросы к серверам Google через выход в
   разрешённом регионе, так что серверная блокировка по региону снимается.
   Свой VPN/прокси при этом **не нужен** — используется встроенный выход.

Всё работает **под обычным пользователем, без root** (sudo не спрашивается).

## Запуск — максимально просто

1. Распакуйте архив. **Если он на общей папке VM** (`/mnt/hgfs/…` у VMware,
   `/media/sf_…` у VirtualBox) — сначала **скопируйте папку в домашнюю**: такие
   папки монтируются `noexec` и запуск оттуда невозможен.
2. Правый клик по **`launch.sh`** → **«Запустить как программу» / «Run as a
   Program»**. Откроется терминал, спросит ключ (из группы t.me/nova_txt),
   появится меню — жмите **1**.

   Не видите «Run as a Program»? Тогда один раз `bash install.sh` — добавит
   «Antigravity Unlocker» в меню приложений, дальше запуск обычным двойным кликом.

3. После пункта 1 **закройте Antigravity полностью и откройте снова** — language
   server подхватит прокси, и ошибка 400 уйдёт.

## Как отключить

Пункт **7** в меню (полный откат) или **6** (только прокси-маршрут) — уберут
локальный прокси, `HTTPS_PROXY` и вернут патч. Вручную: удалить
`~/.config/environment.d/ag-unlocker.conf` и `systemctl --user disable --now
ag-unlocker-proxy`.

## Если установка не нашлась автоматически

Пункт **3** — указать путь вручную. Типичные места: `/opt/antigravity`,
`~/.local/share/antigravity`, `~/.local/bin` (CLI). Snap-версия не патчится
(read-only), используйте не-snap установку.

## Файлы

| Файл | Что это |
|---|---|
| `ag_unlocker` | патчер + прокси (ELF x86-64) |
| `launch.sh` | обёртка: открывает терминал, запускает под пользователем |
| `Antigravity-Unlocker.desktop` | ярлык |
| `install.sh` | добавляет ярлык в меню приложений |
